# 참석 의사 · 방명록 연결 (구글 시트 + Apps Script)

비용 0원, 카드 등록 없이 본인 구글 계정의 시트에 응답을 모읍니다.
휴대폰 브라우저에서 **데스크톱 사이트 보기**를 켜면 설정할 수 있습니다.

## 설정 순서

1. 구글 시트 새 파일을 만들고 이름을 `청첩장 응답`으로 합니다. (시트는 **비공개**로 둡니다)
2. 확장 프로그램 → Apps Script 를 열고, 기본 코드를 지운 뒤 `Code.gs` 내용을 붙여넣고 저장합니다.
3. 배포 → 새 배포 → 유형 **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
4. 권한 허용 → "고급" → "이동" → 허용합니다.
5. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. 저장소 Settings → Secrets and variables → Actions → Variables 에 `RSVP_FORM_URL` 을 추가하고 웹 앱 URL을 넣습니다.
   (로컬 테스트는 `.env` 의 `RSVP_FORM_URL=` 에 넣습니다)
7. `main` 에 반영되면 배포 후 `config.js` 에 주소가 주입됩니다.

## 시트 구성

| 시트 | 열 |
|---|---|
| 참석의사 | 접수 시각, 이름, 참석 여부, 동행(명), 식사 |
| 방명록 | 접수 시각, 이름, 메시지, 공개 동의 |

## 수정 후 주의

- `Code.gs` 를 바꾸면 **배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다. (URL은 그대로 유지)
- 공개 목록은 웹 앱 주소에 `?action=list` 를 붙여 조회합니다. 공개 동의(`동의`)한 행만 최신순 최대 200건을 내려주며, 페이지에는 고정 높이 스크롤 박스로 표시됩니다.
- 연락처는 받지 않습니다. 예식 후에는 시트의 이름·메시지를 정리하거나 비공개로 보관합니다.
- 웹 앱 주소는 누구나 호출할 수 있으므로 길이 제한, 숨은 입력칸, 클라이언트 전송 간격 제한을 함께 둡니다.
